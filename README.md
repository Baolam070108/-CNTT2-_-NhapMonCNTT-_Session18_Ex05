1. VẤN ĐỀ LÀ GÌ?

- **Đội ngũ GreenLogistics cần các tiện ích mở rộng để hỗ trợ kiểm tra API GPS, tăng hiệu suất làm việc và chặn quảng cáo độc hại. Tuy nhiên, cài quá nhiều Extension có thể khiến trình duyệt tiêu tốn RAM và bị chậm.**

2. YÊU CẦU LÀ GÌ?

- **Lựa chọn 5 Extensions thuộc 3 nhóm Dev Suite, Productivity và Security; thiết lập quyền Site Access và hướng dẫn kiểm tra mức tiêu thụ tài nguyên.**

3. CÁCH LÀM:

- Phần 1. Phân tích:

JSON Viewer giúp hiển thị dữ liệu API dạng JSON thô thành cấu trúc dễ đọc, có thể mở rộng và thu gọn các trường dữ liệu. Nhờ đó, kỹ sư dễ kiểm tra thông tin GPS và phát hiện lỗi dữ liệu từ máy chủ.

- Phần 2. Triển khai:

Danh sách 5 tiện ích:
+ JSON Viewer: Đọc và kiểm tra dữ liệu JSON.
+ ColorZilla: Lấy và kiểm tra mã màu trên giao diện.
+ ColorPick Eyedropper: Chọn mã màu trực tiếp trên trang web.
+ uBlock Origin Lite: Chặn quảng cáo và nội dung gây phiền nhiễu.
+ Wappalyzer: Nhận biết công nghệ được sử dụng trên website.

Cách ghim Extension:
+ Mở Chrome Web Store và cài đặt tiện ích.
+ Nhấn biểu tượng Extensions (hình mảnh ghép).
+ Nhấn biểu tượng ghim bên cạnh tiện ích cần dùng.
+ Vào Manage Extensions → Site Access → chọn On click để chỉ cấp quyền khi cần.

- Phần 3. Kiểm thử:

Khi trình duyệt bị lag:
+ Truy cập chrome://extensions.
+ Chọn tiện ích cần kiểm tra.
+ Nhấn Details để quản lý và kiểm tra hoạt động.
+ Mở Chrome Task Manager bằng Shift + Esc để xem mức sử dụng RAM và CPU của từng Extension.
+ Tắt hoặc gỡ những tiện ích không cần thiết.
